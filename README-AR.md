# سجل المبيعات والأقساط — نسخة التطبيق

المجلد فيه 3 طرق، وأسهلهم **pwa** (بيشتغل على الأندرويد والآيفون وويندوز وماك من نفس الملفات، وبيشتغل بدون إنترنت بعد أول فتح).

## أولًا: pwa (الموصى به)

التطبيق محتاج يتحط على موقع بـ https عشان المتصفح يسمح بتثبيته. أسرع طريقة مجانية:

1. افتح https://app.netlify.com/drop (سجّل بإيميل لو طلب).
2. اسحب مجلد **pwa** كله على الصفحة. هيطلع لك رابط زي `https://xxxx.netlify.app`.
3. افتح الرابط على الجهاز اللي عايز تثبّت عليه:
   - **أندرويد (Chrome):** ⋮ ثم "تثبيت التطبيق".
   - **آيفون (Safari):** زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".
   - **ويندوز / ماك (Chrome أو Edge):** أيقونة التثبيت في شريط العنوان، أو ⋮ ثم "حفظ ومشاركة" ثم "تثبيت".
4. هتلاقي أيقونة التطبيق ويفتح في نافذة مستقلة.

لتحديث التطبيق بعد أي تعديل: استبدل `index.html` وغيّر رقم النسخة في `sw.js` (`installments-v1` إلى `v2`) وارفع المجلد تاني.

## ثانيًا: برنامج كمبيوتر (exe / dmg)

1. ثبّت Node.js من https://nodejs.org
2. داخل مجلد **desktop** شغّل: `npm install` ثم `npm run dist`
3. ملف التثبيت هيظهر في مجلد `dist`.

## ثالثًا: تطبيق أندرويد (APK)

محتاج Android Studio. داخل مجلد **android** شغّل: `npm install` ثم `npx cap add android` ثم `npx cap sync` ثم `npx cap open android`، وبعدها Build > Build APK(s).
(الطريقة الأولى أسهل وبتدي نفس النتيجة على أندرويد.)

## مهم: البيانات

- في كل الطرق دي البيانات بتتحفظ **على الجهاز نفسه**، ومش بتتزامن بين التليفون والكمبيوتر.
- التزامن اللحظي بين الأجهزة شغال في **رابط Claude** (النسخة الأونلاين) بس.
- لنقل البيانات بين الأجهزة: زر **💾 نسخة احتياطية** في جهاز، و**استعادة** في الجهاز التاني.
- اعمل نسخة احتياطية بانتظام. مسح بيانات المتصفح أو حذف التطبيق بيمسح البيانات.
- التصدير والرفع بتاع الإكسيل محتاجين إنترنت أول مرة (لتحميل مكتبة الإكسيل)، وبعدها بتتخزن للتشغيل بدون إنترنت.
