# تحويل سجل الأقساط إلى برنامج

المجلد فيه مشروعين: `desktop` (برنامج للكمبيوتر) و `android` (تطبيق أندرويد).
الأسهل والأضمن هو برنامج الكمبيوتر، ابدئي به.

## أولًا: برنامج الكمبيوتر (ويندوز / ماك)

1. نزّلي وثبّتي Node.js (النسخة LTS) من https://nodejs.org
2. افتحي سطر الأوامر (Terminal أو Command Prompt) داخل مجلد `desktop`.
3. شغّلي الأمرين:

        npm install
        npm run dist

4. بعد دقائق هتلاقي ملف التثبيت داخل مجلد `dist` (ملف `.exe` على ويندوز أو `.dmg` على ماك). ثبّتيه كأي برنامج.

للتجربة بدون بناء: `npm install` ثم `npm start`.

## ثانيًا: تطبيق أندرويد (APK)

محتاج Android Studio (مجاني) وهو أثقل في التجهيز:

1. ثبّتي Node.js و Android Studio.
2. داخل مجلد `android` شغّلي:

        npm install
        npx cap add android
        npx cap sync
        npx cap open android

3. في Android Studio: من القائمة Build ثم Build APK(s).
4. انقلي ملف الـ APK للتليفون وثبّتيه (فعّلي تثبيت التطبيقات من مصادر غير معروفة).

## مهم: البيانات

- البيانات بتتحفظ داخل البرنامج على الجهاز نفسه ولا تتزامن مع الرابط ولا مع جهاز آخر.
- استخدمي زر **نسخة احتياطية** داخل البرنامج بانتظام واحتفظي بالملف في مكان آمن (درايف أو واتساب).
- لو عملتي نسخة من الرابط الأونلاين، تقدري تنقلي البيانات: زر نسخة احتياطية هناك ثم استعادة هنا.
- في تطبيق الأندرويد قد لا يعمل تنزيل ملفات التصدير والنسخ الاحتياطي داخل التطبيق نفسه. لو حصل ذلك، استخدمي برنامج الكمبيوتر أو الرابط لهذه العمليات.

## تحديثات النسخة الجديدة

- **استيراد Excel**: زر "📥 استيراد Excel" (xlsx أو csv). الصف الأول عناوين، المطلوب على الأقل: الاسم، المبلغ. اختياري: المنتج، الهاتف، العنوان، تاريخ البيع، عدد الأقساط، المبلغ الأصلي، أقساط مدفوعة. المكرر بيتخطّى.
- **تصدير / نسخة احتياطية في الأندرويد**: بتفتح قائمة مشاركة تحفظي منها الملف (درايف، واتساب، الملفات).
- **الرقم السري والبصمة**: تسجيل أو إلغاء أي قسط بيطلب البصمة (لو متاحة) أو الرقم السري. زر "🔒 الرقم السري" لتغييره.
- **المبلغ الأصلي** لكل عميل (يدوي) وإجماليه في الشاشة الرئيسية، وتبويب **مبالغ خاصة** بإجمالي منفصل.
- آخر تحديث بالتاريخ والوقت أعلى الشاشة. والفرق في التقرير الشهري = 0 لو المستحق صفر.
